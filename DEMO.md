## 5. Reproduce

```bash
cd packages/foundry
forge test                       # 87 tests passed, 0 failed (unit, fuzz, invariant 256 runs x depth 100)
script/run.sh SeedDemo           # fresh Pak Ahmad + Ibu Siti on Arbitrum One (keys from ~/.config/mabrur, never the repo)
script/proof.sh                  # mines the four adversarial reverts and checks each decoded error
script/run.sh DemoRun            # the success ledger; DemoRefund >= 11 min later
script/cost.sh                   # per-pilgrim cost from receipts
```
No step has a mock, offline or dry-run flag: every script broadcasts to Arbitrum One.
